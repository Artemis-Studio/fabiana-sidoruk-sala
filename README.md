# Sala de Operações MktOps — Fabiana Sidoruk

> **Esta é a infraestrutura de marketing da Fabiana Sidoruk, operada via Claude Code.** Tudo está aqui dentro.

## Setup — primeira vez

1. **Instalar Claude Code:** `npm install -g @anthropic-ai/claude-code` (precisa Node 18+)
2. **Autenticar:** rode `claude` e siga o login.
3. **Abrir a Sala:** `cd "caminho/para/fabiana-sidoruk" && claude`

Ao abrir, o Claude lê o `CLAUDE.md` automaticamente — já sabe quem é a Fabiana Sidoruk, as regras de copy, e tem todas as skills.

## Como pedir tarefas

Bom pedido tem 3 partes: **(1) qual tarefa · (2) pra qual público/objetivo · (3) qual ângulo/hook.**

> *"Roteiro de reel de 1 minuto pra adulto que repete o mesmo padrão no trabalho, com gancho 'Quantas coisas você chama de meu jeito sem nunca ter parado pra pensar?', focando nas relações com o trabalho e o dinheiro."*

## O que tem aqui

- `brand-context.md` — quem a Fabiana Sidoruk é de verdade (ler antes de copy)
- `copy-routing.md` — "quero X → use a skill Y" (índice por intenção; comece por aqui)
- `cerebro-de-copy/` — a camada estratégica de copywriting
- `playbook-narrativas-mktops.md` — o modelo de carrossel (4 atos)
- `design-system/` — identidade visual (abra `design-system/guia-visual.html` no navegador)
- `brand-profile.json` — perfil de marca que as skills de anúncio e vídeo leem
- `calls/` — o que foi conversado nas reuniões
- `pesquisa-mercado/` · `spy/` — inteligência de mercado e concorrência
- `producao/` — imagens de inserção, capas e legendas dos reels
- `entregas/videos-e-carrosseis/` — reels, vídeos animados e carrosséis finalizados
- `conteudo/` — peças em produção: carrosséis-modelo e roteiros dos reels animados
- `entregas/2026-10/` — os 8 reels editados (vídeo, capa e fala de cada um) e os 3 reels animados de exemplo

## Regra de ouro

Toda copy passa por `copywriting-guardrails` antes de virar arquivo final. Copy de ads passa também por `copy-format-check`.
